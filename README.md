# Gosmart Platform Media Files

This repository contains the media assets used by the Gosmart platform, including cover images for learning programs and assessment-related visuals.

## Included folders

- `lps-covers/` — covers for learning program sections
- `qu-covers/` — question/quiz-related cover assets
- `placeholder.png` — generic placeholder image

## Notes

These files are intended to be reused across the platform and kept in a shared public repository for easy access and distribution.
